# KPIboard demo

Interactive demo of an OKR and KPI tracker built on Microsoft 365. All people and data are fictional.

Open `index.html` in a browser, or publish it with GitHub Pages (Settings > Pages > Deploy from a branch > main, root).

## Try this
1. Overview: see how many objectives are on track, at risk or behind, measured against where each should be today.
2. Company OKRs: open an objective to see its key results and the KPIs that drive them.
3. People > Jonas Keller: move a slider. Jonas's score, the KPI, the key result, the objective and the department all update.
4. People > Kai Lindqvist (new joiner) and Mateo Silva (left): their progress is shown but does not count toward company goals.
5. Achievements: add a win and link it to an objective.
6. Performance review: switch period, fill in values and scores, release to the employee, then freeze the period.
7. Reports: open Frozen snapshots to download what was saved, or any other report as CSV or PDF.
8. Switch "Signed in as" to Jonas Keller to see what an employee can and cannot edit.

Data resets on reload. Names and contact details are set in `CONFIG` at the top of the script.
